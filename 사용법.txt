시작 관리자 - 사용법

부팅·로그온 때 자동으로 켜지는 프로그램을 한 화면에서 보고 관리하는 프로그램입니다.

[설치]
1. StartupManager 폴더를 지우지 않을 곳에 둡니다. (예: C:\Program Files 가 아닌 내 문서나 C:\Tools)
2. StartupManager.exe 를 실행합니다.
3. 위쪽 "로그온 실행기 등록"을 누릅니다. 이제 로그온할 때 시작 관리자가 트레이에 뜨고,
   "관리 실행기"에 넣은 프로그램을 순서대로 켭니다.
   ※ 폴더를 옮겼다면 "로그온 실행기 등록"을 한 번 더 누르세요.

[할 수 있는 것]
- 한눈에 보기: 작업 스케줄러, 레지스트리 Run, 시작프로그램 폴더의 자동 실행 항목과 실행 중 여부, 마지막 실행 결과
- 켜기/끄기: 항목을 지우지 않고 끄기만 합니다 (작업 관리자의 '시작 앱'과 같은 방식). 🛡 표시는 관리자 확인 창이 뜹니다.
- 목록에서 삭제: 필요 없어진 항목을 아예 지웁니다. Run 값·작업은 삭제, 바로 가기는 휴지통으로 보내고,
  지우기 전 내용은 설정 폴더의 deleted 폴더에 백업합니다. 관리 항목을 지우면 옮겨 오기 전 원래 항목도 같이 지웁니다.
- 설정…(또는 더블클릭): 최소화해서 실행, 켜기 전 대기 시간, 중복 실행 확인용 프로세스 이름
  · 레지스트리 Run/시작프로그램 폴더 항목에 설정을 저장하면 "관리 실행기"로 옮겨집니다.
    원래 항목은 꺼지기만 하고, "관리 해제"를 누르면 원래대로 돌아갑니다.
- 중복 실행 방지: 이미 켜져 있는 프로그램은 다시 켜지 않습니다.
  · "명령줄 확인"에 글자를 적으면 명령줄에 그 글자가 든 프로세스만 같은 프로그램으로 봅니다.
    pythonw.exe 로 여러 스크립트를 켤 때 필요하며, python 항목은 비워 두면 스크립트 파일 이름을 자동으로 씁니다.
    (관리자 권한으로 도는 프로세스는 명령줄을 못 읽어 '꺼져 있음'으로 보일 수 있습니다.)
- 꺼지면 다시 켜기: 로그온 실행기가 로그온 뒤에도 계속 돌면서 60초마다 확인해 다시 켭니다.
  10분 안에 5번 넘게 죽으면 30분 쉽니다. 기록은 "실행 기록" 탭에 남습니다.
- 확인할 경로: 예를 들어 Z:\ 를 적으면, 프로그램은 돌고 있는데 Z:\ 가 두 번 연속 안 보일 때 끄고 다시 켭니다.
- 새 관리 항목: 실행 파일, Steam 게임(AppId), 작업 스케줄러 작업을 로그온 때 켜도록 추가합니다.
- 창의 X 를 누르면 트레이로 숨습니다. 완전히 끄려면 트레이 아이콘 오른쪽 클릭 → 종료.

[설정·기록 위치]
%APPDATA%\StartupManager  (config.json, launcher.log) — 위쪽 "설정 폴더" 버튼으로 열 수 있습니다.
포터블 모드: StartupManager.exe 옆에 config.json 파일이 있으면(내용이 {"items": []} 인 빈 파일이라도) 그 폴더를 씁니다.

[이미 등록했던 경우 새 버전으로 바꿀 때]
트레이에서 종료 → 폴더 덮어쓰기 → StartupManager.exe 실행 → "다시 등록" (감시 기능 때문에 작업 시간 제한이 없어집니다).
다시 켜기는 다음 로그온부터 동작합니다.

[지우기]
"등록 해제"를 누른 뒤, 옮겨 둔 항목은 "관리 해제"로 되돌리고 폴더를 지우면 됩니다.
